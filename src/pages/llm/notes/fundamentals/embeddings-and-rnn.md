> 根据学习记录整理的入门理解。词级模型与现代大语言模型的 token 切分不完全相同，下面分别指出。

## 词嵌入：从离散编号到向量

一个词或 token 先被表示为离散编号，再查表映射到一个可训练的向量。**维度是设计选择**，不是“既不高也不低”的固定值。训练后，向量之间可能呈现对具体任务有用的相似性；可以用点积或余弦相似度作比较，但**不能说每一维都稳定对应一个能用中文命名的特征**。语义通常分布在多个维度，也取决于训练目标和数据。

传统词向量常以“词”为单位；大语言模型一般由 tokenizer 先切成 token，可能是整词、词的一部分或其他片段。向量表示的对象要以实际 tokenizer 为准。

## RNN：把前面的状态带到下一步

一个简化的循环神经网络可以写成：

```text
hₜ = f(Wₓ xₜ + Wₕ hₜ₋₁ + b)
yₜ = g(Wᵧ hₜ)
```

`xₜ` 是当前输入向量，`hₜ₋₁` 是上一时刻的隐藏状态，`hₜ` 是更新后的状态；输入矩阵、隐藏状态矩阵和输出矩阵是共享的可训练参数。因为 `hₜ` 依赖 `hₜ₋₁`，**同一序列沿时间步通常必须按顺序计算**，但不同样本仍可以并行处理。

这种递推让模型能利用顺序信息，不过长距离依赖不易训练；早期信息可能难以保留，反向传播也可能遇到梯度消失或爆炸。不能简单理解成“时间一长信息一定全部丢失”。LSTM/GRU 等是为改善部分长期依赖问题提出的变体。

## 记住这个对比

嵌入解决的是“离散 token 如何进入连续向量空间”；RNN 进一步解决“处理序列时怎样带着历史状态往前走”。之后学习 Transformer 时，重点再看它如何用注意力在训练中处理位置之间的信息交互。
