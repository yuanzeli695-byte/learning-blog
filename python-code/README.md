# Python 学习代码区

这里展示从本地个人练习**整理而来**的分段学习笔记，不是原文件的逐字备份。

每篇笔记按主题放置：

- `基础语法/`：输入输出、运算、条件与循环
- `函数/`：参数、作用域、装饰器
- `数据结构/`：字符串、列表、字典、集合
- `文件与异常/`：文件读写与安全替换
- `练习项目/`：以后的小项目

## 内容结构

一个原文件对应一份章节清单 `.json` 和一个同名文件夹；文件夹里的 `.py` 是**按功能拆出的独立代码段**。例如：

```text
基础语法/
  10-while循环.json
  10-while循环/
    01-计数.py
    02-break-continue.py
    03-三次尝试.py
```

章节清单中的每一段包括 `title`（标题）、`intro`（放在代码块前、以我的视角写的说明）和 `file`（相对于同名文件夹的 `.py` 文件名）。代码块本身也有简短的第一人称注释。页面由这些清单生成；仅上传 `.py` 而没有更新清单，不会自动显示。
