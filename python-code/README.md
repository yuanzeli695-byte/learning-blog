# Python 学习代码

把你自己练习的 `.py` 文件放在相应主题目录中：

- `基础语法/`：变量、条件、循环等
- `函数/`：定义函数、参数、返回值等
- `数据结构/`：列表、字典、集合等
- `文件与异常/`：文件读写、异常处理等
- `练习项目/`：小项目、综合练习等

例如，把自己写的 `my_function.py` 放入 `函数/`，构建后会自动显示在博客的 **Python 学习** 页面。不需要运行网站上的 Python 代码；网站只展示源码。

如果希望显示标题、日期和学习说明，在同目录下新建同名的 `.json` 文件，例如 `my_function.json`：

```json
{
  "title": "函数参数练习",
  "date": "2026-09-27",
  "summary": "练习位置参数与返回值。",
  "notes": ["参数是传给函数的输入。", "return 用来把结果返回给调用方。"]
}
```

`.json` 是可选的；没有它也能展示代码，标题默认取文件名。`notes` 是页面旁的简短学习要点；代码里的 `#` 注释由我在收到你的真实练习后添加，不会自动杜撰或改写学习过程。

**发布前检查：**代码和说明会进入公开 Git 仓库。请勿包含密码、API Key、个人隐私或不准备公开的文件路径。提交由我帮助检查，发现错误会说明，不会暗中修改原代码的行为。
